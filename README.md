# 👃 Nozease : site vitrine

Site vitrine statique, sur une seule page, présentant les produits **Nozease** destinés à améliorer la respiration.

## 📌 Sections

- **Hero** : accroche « Transformez votre respiration, transformez votre vie »
- **Nos solutions phares** : gammes *Active*, *Daily* et *Night*
- **Avis clients**
- **Test de respiration** : la différence Nozease
- **Contact**

Le site est pensé pour l'accessibilité (attributs ARIA, balises sémantiques).

## 🛠️ Technologies

HTML5 · CSS3 (intégré) · images WebP

## 🚀 Lancer le projet

Ouvrir `index.html` dans un navigateur.
